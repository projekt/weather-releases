# Weather Conditions — Desktop Releases

This repository hosts **only the compiled desktop build artifacts** (Windows, macOS, Linux) for the [Weather Conditions](https://weather.srdapp.rs) app.

The application source code is maintained in a private repository. Releases here are published automatically by CI whenever a new version is tagged.

- **Windows / macOS / Linux downloads:** see the [Releases page](../../releases/latest)
- **App website:** https://weather.srdapp.rs
- **Privacy policy:** https://weather.srdapp.rs/privacy.html
